My goal is help you all navigate the world of computational physics by giving you a starting off point. We will be doing both computational 
and analytic techniques. But we will focus on the computational techniques a lot more since in physics, most systems are not solvable analytically.

By the end, my goal is that you will be able to:
1. Code basic programs in Python
2. Solve linear and nonlinear equations with the help of programming
3. Simulating differential equations (both ordinary and partial)
